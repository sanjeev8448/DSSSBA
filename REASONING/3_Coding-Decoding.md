## B. Reverse Alphabet

In reverse coding, letters are paired from opposite ends of the alphabet.

|Normal Letter|Normal Position|Reverse Letter|Reverse Position|
|---|---|---|---|
|A|1|Z|26|
|B|2|Y|25|
|C|3|X|24|
|D|4|W|23|
|E|5|V|22|

|L|12|O|15|
|M|13|N|14|

### Reverse Position Formula

Reverse Position = 27 − Normal Position

**Example:** C has normal position 3.

Reverse position = 27 − 3 = 24

The 24th letter is X.

**Answer: C ↔ X**

Remember: The normal and reverse positions of a letter always add up to 27.

# 2. Letter Coding

In letter coding, letters are changed according to a fixed or changing shift, such as +1, +2, −1 or −2.

## Type A: Forward Shifting

**Example:** If CAT is coded as DBU, how is DOG coded?

Identify the pattern:

- C → D = +1
    
- A → B = +1
    
- T → U = +1
    

Apply the same rule to DOG:

- D → E
    
- O → P
    
- G → H
    

**Answer: DOG → EPH**

## Type B: Backward Shifting

**Example:** If LION is coded as KHNM, identify the rule.

- L → K = −1
    
- I → H = −1
    
- O → N = −1
    
- N → M = −1
    

Each letter moves one position backward.

**Rule: Shift every letter by −1.**

## Type C: Different Shifts for Different Letters

**Example:** If ACE becomes BDF:

- A → B = +1
    
- C → D = +1
    
- E → F = +1
    

This example uses the same shift for every letter.

However, some questions use alternating or changing shifts, such as +1, −1, +1, −1.

**Exam tip:** Inspect each letter separately rather than automatically assuming a uniform shift.

## Type D: Increasing Shifts

**Example:** If ABC becomes BDF, how does DOG change under the same rule?

Identify the pattern:

- A → B = +1
    
- B → D = +2
    
- C → F = +3
    

Apply increasing shifts to DOG:

- D + 1 = E
    
- O + 2 = Q
    
- G + 3 = J
    

**Answer: DOG → EQJ**

# 3. Number Coding

In number coding, letters may be replaced by their alphabetical positions. The positions may then be added, subtracted or multiplied.

## Type A: Direct Alphabet Values

**Example:** If CAT = 3-1-20, find the code for DOG.

- D = 4
    
- O = 15
    
- G = 7
    

**Answer: DOG = 4-15-7**

## Type B: Sum of Letter Positions

**Example:** If CAT = 24, find the code for DOG using the same rule.

For CAT:

C + A + T = 3 + 1 + 20 = 24

For DOG:

D + O + G = 4 + 15 + 7 = 26

**Answer: 26**

## Type C: Reverse-Alphabet Values

**Example:** Find the reverse-alphabet code for CAT.

- C → X = 24
    
- A → Z = 26
    
- T → G = 7
    

**Answer: 24-26-7**

**Important:** A question may use the reverse letter itself, its reverse position or a mathematical operation on the position. Follow the rule stated in the question.

# 4. Word Coding

In word coding, an entire word is transformed using a pattern. Common methods include reversing the word, rearranging letters or shifting every letter.

## Type A: Reverse the Word

**Example:** If TABLE is coded as ELBAT, how is CHAIR coded?

- TABLE → ELBAT
    
- CHAIR → RIAHC
    

**Answer: RIAHC**

## Type B: Exchange the First and Last Letters

**Example:** If the first and last letters are exchanged, TABLE becomes EABLT.

For CHAIR:

- First letter C and last letter R are exchanged.
    
- C H A I R → R H A I C
    

**Answer: RHAIC**

## Type C: Shift Every Letter

**Example:** If BOOK becomes CPPL, every letter moves forward by one position.

Apply the same rule to PEN:

- P → Q
    
- E → F
    
- N → O
    

**Answer: QFO**

### Exam Tip

Check whether the rule:

- Changes each letter.
    
- Reverses the entire word.
    
- Exchanges particular letter positions.
    
- Rearranges letters.
    
- Changes the word into a numerical value.
    

# 5. Substitution Coding

In substitution coding, one letter or word is replaced by another according to a stated or implied mapping.

## Example 1: Letter Substitution

Suppose:

- A is replaced by D.
    
- B is replaced by E.
    
- C is replaced by F.
    
- The same pattern continues for the remaining letters.
    

Every letter shifts forward by three positions.

Find the code for CAT:

- C → F
    
- A → D
    
- T → W
    

**Answer: FDW**

## Example 2: Word Substitution

Suppose the question states:

- “sun” means “moon”.
    
- “moon” means “star”.
    
- “star” means “planet”.
    

If asked which code word represents the actual moon, the answer is **sun**, because the code word “sun” represents the actual moon.

**Important:** Follow the mapping given in the question, even if the replacement sounds illogical in ordinary language.

# 6. Chinese Coding (Coded Sentences)

Chinese coding questions provide several sentences with corresponding codes. Your task is to determine which code represents a particular word.

The codes are often meaningless strings. The solution depends on comparing sentences and identifying common words and common codes.

## Worked Example

|Sentence|Code|
|---|---|
|sky is blue|ka na pa|
|sea is deep|ta na ma|
|sky looks deep|ka sa ma|

Find the code for **is**.

### Step 1: Compare the First and Second Sentences

- Common word: is
    
- Common code: na
    

Therefore, is = na.

### Step 2: Verify Using the Other Sentences

Compare the first and third sentences:

- Common word: sky
    
- Common code: ka
    

Compare the second and third sentences:

- Common word: deep
    
- Common code: ma
    

The mappings are consistent.

**Answer: is = na**

## Method to Solve Coded Sentences

1. Find two sentences with exactly one common word.
    
2. Identify the code common to those sentences.
    
3. Repeat the process with other sentence pairs.
    
4. Confirm the mapping using a third sentence wherever possible.
    
5. Eliminate already identified words and codes when comparing longer sentences.
    

# 7. Sentence Coding

Sentence coding is closely related to Chinese coding. The question provides codes for complete sentences, and you identify individual word codes by comparing the sentences.

## Worked Example

|Sentence|Code|
|---|---|
|ram likes mango|pi ko na|
|ram likes apple|pi ko sa|
|mango is sweet|na tu mi|

Find the code for **mango**.

### Step 1: Compare the First and Second Sentences

Common words:

- ram
    
- likes
    

Common codes:

- pi
    
- ko
    

Therefore, ram and likes correspond to pi and ko, in either order.

### Step 2: Compare the First and Third Sentences

The common word is mango.

The only common code is na.

**Answer: mango = na**

## Important Distinction

“Chinese coding” and “sentence coding” are often used interchangeably in reasoning books.

In both formats, solve by identifying common words and common codes. Do not assign codes based on their sound or ordinary meaning.

# 8. Mixed Coding

Mixed coding combines multiple rules. A word may be shifted forward, converted into alphabet positions, reversed or subjected to arithmetic operations.

## Type A: Letter Shift + Alphabet Positions

**Example:** Shift each letter of CAT forward by one, then convert the resulting letters into numbers.

Step 1: Shift the letters.

CAT → DBU

Step 2: Convert the letters into positions.

- D = 4
    
- B = 2
    
- U = 21
    

**Answer: 4-2-21**

## Type B: Letter Positions + Arithmetic

**Example:** If a word's code is the sum of its letter positions, calculate the code for BAD.

- B = 2
    
- A = 1
    
- D = 4
    

Code = 2 + 1 + 4 = 7

**Answer: 7**

## Type C: Reverse Alphabet + Sum

**Example:** Find the sum of reverse-alphabet positions for BAD.

- B → Y = 25
    
- A → Z = 26
    
- D → W = 23
    

Code = 25 + 26 + 23 = 74

**Answer: 74**

## Type D: Multiple Transformations

**Example:** Reverse the word and then shift every letter one position forward. Find the code for CAT.

Step 1: Reverse the word.

CAT → TAC

Step 2: Shift every letter forward by one.

- T → U
    
- A → B
    
- C → D
    

Result = UBD

**Answer: UBD**

**Exam tip:** Write each transformation separately to avoid mistakes in mixed-coding questions.

# 9. Quick-Solving Rules for DSSSB

|Question Pattern|First Thing to Check|
|---|---|
|Letters replaced with letters|Forward or backward shifts|
|Letters replaced with numbers|Alphabet positions|
|Reverse-looking code|Reversed word or reverse alphabet|
|A word mapped to a number|Sum, difference or product of positions|
|Several coded sentences|Common words and common codes|
|Mixed numerical and letter code|Each transformation step by step|
|Irregular letter shifts|Calculate the shift for each letter separately|
|Letters rearranged|Reversal or exchange of particular positions|
|Unfamiliar word substitutions|Follow the exact mapping given|

## Common Mistakes to Avoid

1. **Forgetting alphabet wraparound:** A letter shifted forward beyond Z may return to A, depending on the stated rule.
    
2. **Confusing normal and reverse positions:** For example, C has normal position 3 and reverse position 24.
    
3. **Assuming every letter has the same shift:** Check for increasing or alternating shifts.
    
4. **Assigning codes too early:** Compare other sentences before confirming a word-code mapping.
    
5. **Ignoring transformation order:** Reversing a word and then shifting its letters can produce a different result from shifting first and reversing afterward.
    
6. **Confusing a letter with its numerical value:** A reverse letter and its reverse-alphabet position are not the same thing.
    

# Final Revision Checklist

Before attempting DSSSB coding-decoding questions, make sure you can:

- Recall all 26 alphabet positions.
    
- Use reverse-alphabet pairs and the formula 27 − normal position.
    
- Identify forward, backward and increasing letter shifts.
    
- Convert words into alphabet-position codes.
    
- Calculate sums of letter positions.
    
- Reverse words and exchange letter positions.
    
- Solve substitution-based questions.
    
- Decode sentences by comparing common words and codes.
    
- Apply multiple transformations in the correct order.
    

**Golden rule:** Identify the coding rule first, verify it against the given example, and only then apply it to the required word or sentence.
